# Galan Electrode Boiler and Navigator Temperature Controller Manuals (EN / HU / RU)

Transcribed and translated user manuals for **GALAN electrode boilers** (Ochag, Geyser, Vulkan series) and the **GALAN Navigator** two-channel electronic temperature controller, in English, Hungarian and the original Russian.

Each manual covers specifications, installation into the heating system, electrical wiring diagrams, filling and adjusting the heat-transfer fluid, start-up, maintenance and troubleshooting.

## Notes

- Text follows the printed booklets page by page. `<!-- page N -->` markers point to the original page numbers.
- Diagrams are cropped from photos of the original booklets. Labels inside the drawings are in Russian, and a translated legend is given under each figure.
- Warranty, sale certificate, warranty coupon and service log pages are left out.

## Magyar

A GALAN elektródás kazánok (Ocsag, Gejzer, Vulkán sorozat) és a GALAN Navigator kétcsatornás elektronikus hőmérséklet-szabályozó kezelési útmutatói magyar, angol és eredeti orosz nyelven. A jótállási, értékesítési és szervizlap oldalak kimaradtak.
